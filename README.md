# SolidityVoid

SolidityVoid is a distributed, high-performance data processing platform engine enabling auto-scaling, real-time data analytics capabilities.

With SolidityVoid, you get a lightweight tool that stays out of your way.

**What you get**

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/SolidityVoid.git`
2. `cd SolidityVoid`
3. Install in editable mode: `pip install -e .`

## Configuration

SolidityVoid is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
